# 01: Your First API Translation

## 🎯 Mission

Transform your working Postman requests into Python code and see them come alive! This is where your API journey moves from testing to programming.

## 🎖 Goals  

- [ ] Export Python code from your Postman Dad Jokes request
- [ ] Run the exported code in Python and see it work
- [ ] Export Python code from your Postman Deck of Cards request
- [ ] Understand the connection between Postman and Python Requests

## 💡 Hints

### Step 1: Export from Postman

- Open your working Dad Jokes request in Postman
- Click the "Code" button (usually in the right panel)
- Select "Python - Requests" from the dropdown
- Copy that code - it's your starting point!

### Step 2: Make it Python

- The exported code might look complex, but focus on the `requests.get()` part
- That's the magic - the same request you tested is now programmable!

### Step 3: Run and Celebrate

- Save the code as a `.py` file and run it
- You just made your first programmatic API call!

## 🚀 Ready to Code?

**Start with `dad_jokes.py`** - paste your exported Postman code and make it work!
**Then try `deck_of_cards.py`** - export and run your Deck of Cards request too!

**You've got this!** 🎉 The connection between Postman testing and Python automation starts here!
