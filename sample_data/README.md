# Sample Data Directory

This directory contains example API responses and data files to help you understand the structure of data you'll work with in network automation.

## Files Included

### `dad_joke_response.json`

Example of what the Dad Jokes API returns - helps you understand the JSON structure before writing code.

### `deck_response.json`

Example of what the Deck of Cards API returns when creating a new deck.

### `cards_drawn.json`

Example of what you get when drawing cards from a deck - shows the nested card data structure.

### `network_device_example.json`

Simulated network device API response - shows what real network equipment APIs might return.

## How to Use These Files

1. **Study the Structure**: Open these JSON files to see what API responses look like
2. **Plan Your Code**: Use these examples to understand what fields are available
3. **Test Parsing**: Practice extracting data from these files before hitting live APIs
4. **Reference During Development**: Keep these open while coding to see field names

## 🎯 Learning Tip

Understanding the data structure BEFORE writing code makes development much easier. Study these examples first!
